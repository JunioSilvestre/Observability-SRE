# 05-sre — Site Reliability Engineering (SRE)

Definição de acordos de nível de serviço, gestão de orçamentos de erro, incidentes e postmortems blameless.

## 📂 Subáreas
- [`sli-slo-sla/`](./sli-slo-sla) — **Stack:** `SLI (Indicadores), SLO (Objetivos), SLA (Contratos)` — Métricas orientadas à experiência do usuário e tolerância a falhas.
- [`error-budgets/`](./error-budgets) — **Stack:** `Burn rate alerts, congelamento de deploy` — Gestão do equilíbrio entre inovação/velocidade e estabilidade operacional.
- [`incident-management/`](./incident-management) — **Stack:** `War rooms, escalonamento, papeis de resposta` — Protocolos de comando de incidentes e comunicação transparente em crises.
- [`postmortems/`](./postmortems) — **Stack:** `Blameless postmortem template, lições aprendidas` — Análise de causa raiz (RCA) e planos de ação para prevenção de reincidência.

## 📌 Guia de Execução & Padrões
- Todas as implementações desta pasta seguem os padrões de produção estabelecidos para Observability-SRE.
- Consulte os READMEs de cada subárea para detalhes sobre ferramentas e boas práticas.

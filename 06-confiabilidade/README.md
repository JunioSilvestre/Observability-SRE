# 06-confiabilidade — Engenharia de Confiabilidade e Resiliência

Planejamento de capacidade, estratégias de alta disponibilidade e planos de recuperação de desastres (DRP).

## 📂 Subáreas
- [`availability/`](./availability) — **Stack:** `Alta disponibilidade, redundância N+1, multi-region` — Arquiteturas sem ponto único de falha (Single Point of Failure - SPOF).
- [`capacity-planning/`](./capacity-planning) — **Stack:** `Tendências históricas, projeções de consumo de hardware` — Previsão de esgotamento de recursos com base em taxas de crescimento de carga.
- [`disaster-recovery/`](./disaster-recovery) — **Stack:** `RTO (Tempo), RPO (Dados), testes de restauração` — Estratégias de backup, replicação e failover automático.

## 📌 Guia de Execução & Padrões
- Todas as implementações desta pasta seguem os padrões de produção estabelecidos para Observability-SRE.
- Consulte os READMEs de cada subárea para detalhes sobre ferramentas e boas práticas.

# 04-tracing — Distributed Tracing & OpenTelemetry

Rastreamento distribuído de requisições em microserviços com OpenTelemetry (OTel), Tempo e Jaeger.

## 📂 Subáreas
- [`opentelemetry/`](./opentelemetry) — **Stack:** `OTel Collector, spans, context propagation` — Padronização aberta de instrumentação de aplicações e exportação de traces.
- [`jaeger-tempo/`](./jaeger-tempo) — **Stack:** `Grafana Tempo, Jaeger UI, trace discovery` — Armazenamento em escala de traces integrados a logs e métricas no Grafana.

## 📌 Guia de Execução & Padrões
- Todas as implementações desta pasta seguem os padrões de produção estabelecidos para Observability-SRE.
- Consulte os READMEs de cada subárea para detalhes sobre ferramentas e boas práticas.
